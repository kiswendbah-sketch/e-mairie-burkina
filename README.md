# e-Mairie Burkina 🇧🇫

Application web Flask pour la gestion des citoyens et des demandes municipales au Burkina Faso.

## Fonctionnalités

- Inscription et connexion des citoyens
- Espace citoyen
- Envoi de demandes administratives
- Téléversement de documents
- Suivi du statut des demandes
- Notifications aux citoyens
- Espace administrateur
- Gestion des citoyens
- Gestion des demandes
- Validation ou refus des demandes
- Dépôt des documents officiels

## Technologies

- Python
- Flask
- SQLite
- HTML / CSS / JavaScript
- Bootstrap
- Flask-Bcrypt
